# 💼 Salary Prediction Using Machine Learning

## 📌 Project Overview

This is a Machine Learning web application built using Streamlit that predicts an employee's salary based on:

- Years of Experience
- Education Level
- Age

The model is trained using a Random Forest Regressor.

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

---
